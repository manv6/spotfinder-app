# Legacy — SpotFinder v1.0 (canvas web app)

`index.html` here is the original single-file, zero-dependency SpotFinder: a
venue picker over 40+ hardcoded venue dimensions with a hand-drawn HTML5 canvas
map. It has no real map tiles.

**It is no longer the deployed site.** https://manv6.github.io/spotfinder-app/
now serves the Expo web build of the app in [`../mobile`](../mobile), which uses
a real MapLibre map and shares all its code with the iOS/Android app.

Kept for reference and because it still works standalone — open the file in any
browser, no build step. GPS needs HTTPS or localhost.
